================================================================================
                            USAGE QUICK START
================================================================================

1. Install Dependencies
   pip install -r requirements.txt

2. Set Up Google Cloud
   export GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account-key.json

3. Prepare Images
   - Organize by group prefix (e.g., document_001.tif, document_002.tif)
   - TIFF and JPEG supported

4. Run Pipeline
   python main.py --input-dir ./images --output-dir ./pdfs \
                  --credentials-path ./service-account-key.json

5. Output
   - Searchable PDFs created in output directory
   - One PDF per document group
   - Text searchable via Ctrl+F
